# Five-minute capstone demonstration

1. State the user outcome, run ID, environment, and honest limitation.
2. Trace one source revision to one immutable image digest.
3. Show one failed gate that blocked promotion and the passing reviewed run.
4. Compare the approved GitOps revision with the runtime identity.
5. Show the controlled incident signal, human decision, Git recovery, and
   customer-facing validation.
6. Demonstrate the assistant citation and agent write refusal.
7. Show cost guardrail and independent cleanup evidence.

Use sanitized evidence from one acceptance run. Provide text equivalents for
visual material and do not rely on color alone.
