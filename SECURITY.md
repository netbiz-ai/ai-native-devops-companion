# Security policy

This repository is a learning environment. Do not connect its examples to
production systems or supply production credentials.

Report a vulnerability privately through GitHub's security-advisory feature.
Do not open a public issue containing a secret, private topology, customer
data, exploit details, or unsanitized operational evidence.

The repository intentionally keeps generated evidence, state, audit logs, and
credentials out of Git. A `.gitignore` rule is not a remediation for a secret
that has already entered history.
